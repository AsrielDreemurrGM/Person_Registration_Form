<h1>Formulário de Cadastro de Pessoa Física</h1>
<p>
    This README is also available in <a href="./README.md">English</a>.
</p>
<p>
    Um formulário responsivo para cadastro de pessoas físicas, desenvolvido com
    <strong>HTML5</strong>, <strong>CSS3</strong> e <strong>jQuery</strong>.
    Inclui validação de dados, máscaras para CPF, telefone e CEP,
    e um menu hamburger para exibir ou ocultar o formulário.
</p>
<p>
    🔗 Live Demo: <a href="https://person-registration-form-asrdrgm.vercel.app/" target="_blank">Ver na Vercel</a>
</p>
<h2>Sobre</h2>
<p>
    O projeto permite que usuários registrem informações pessoais com validação de formulário.
    As máscaras garantem o formato correto para CPF, telefone e CEP.
    O formulário pode ser exibido ou ocultado usando o menu hamburger.
</p>
<h2>Tecnologias Utilizadas</h2>
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>jQuery (manipulação do DOM, event listeners, plugins)</li>
    <li>Plugin de Validação do jQuery</li>
    <li>Plugin de Máscara do jQuery</li>
</ul>
<h2>Funcionalidades</h2>
<ul>
    <li>Layout responsivo para desktops, tablets e dispositivos móveis;</li>
    <li>Máscaras de campo para CPF, telefone e CEP;</li>
    <li>Validação do formulário com mensagens de erro claras em português brasileiro;</li>
    <li>Menu hamburger para exibir ou ocultar o formulário.</li>
</ul>
<h2>Notas</h2>
<p>
    Este projeto foi desenvolvido para prática de manipulação de formulários,
    validação e uso de plugins jQuery para melhorar a experiência do usuário.
</p>
