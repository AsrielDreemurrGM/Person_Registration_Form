<h1>Person Registration Form</h1>
<p>
    Este README também está disponível em <a href="./README.pt-br.md">Português</a>.
</p>
<p>
    A responsive person registration form built with
    <strong>HTML5</strong>, <strong>CSS3</strong>, and <strong>jQuery</strong>.
    It includes input validation, field masks for CPF, phone, and CEP,
    and a hamburger menu to toggle form visibility.
</p>
<p>
    🔗 Live Demo: <a href="https://person-registration-form-asrdrgm.vercel.app/" target="_blank">View on Vercel</a>
</p>
<h2>About</h2>
<p>
    The project allows users to register personal information with form validation.
    Field masks ensure correct formatting of CPF, phone numbers, and CEP.
    The form can be hidden or shown using a hamburger menu.
</p>
<h2>Technologies Used</h2>s
<ul>
    <li>HTML5</li>
    <li>CSS3</li>
    <li>jQuery (DOM manipulation, event listeners, plugins)</li>
    <li>jQuery Validation Plugin</li>
    <li>jQuery Mask Plugin</li>
</ul>
<h2>Features</h2>
<ul>
    <li>Responsive form layout for desktops, tablets, and mobile devices;</li>
    <li>Field masks for CPF, phone, and CEP inputs;</li>
    <li>Form validation with clear error messages in Brazilian Portuguese;</li>
    <li>Hamburger menu toggle to show or hide the form.</li>
</ul>
<h2>Notes</h2>
<p>
    This project is designed for practicing form handling, validation,
    and the use of jQuery plugins for a better user experience.
</p>
